## 1. Scope & Primary Intent

**PhantomAFK is developed and published strictly for educational, scientific research, and network protocol demonstration purposes.**

The primary academic and technical objectives of this project are:
1. **Headless Client Protocol Analysis:** Researching lightweight state machine interactions with Minecraft network proxies (e.g., Velocity, BungeeCord) without running heavy GPU/rendering pipelines.
2. **Resource Optimization on Low-Power Architectures:** Demonstrating that headless background daemons can run efficiently on ARM-based mobile devices (Android Termux) with a sub-50 MB RAM footprint, eliminating the excessive energy consumption and system overhead of leaving high-wattage desktop PCs running 24/7.
3. **Native WebSocket Telemetry:** Demonstrating how to communicate with the official Discord Gateway v10 via direct, un-bloated WebSocket frames without bulky third-party abstraction frameworks.
4. **Queue & Anti-Kick Heuristic Exploration:** Studying packet timing and queue preservation mechanisms in automated network transfers.
